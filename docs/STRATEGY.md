# 第一部分　投流内容打法（编导 / 创意总监 / 买家画像 三视角）

## 1. 什么是"买家画像"，为什么它决定投流成败

**买家画像（Buyer Persona）= 用一个具体的"虚拟人"代表你最理想的目标客户。** 它不是"30岁女性"这种人口标签，而是一张能让你"代入对方脑子"的卡片，至少包含 7 个字段：

| 字段 | 含义 | 举例（工厂展示·采购商） |
|---|---|---|
| 身份/角色 | 他在交易里是谁 | 海外中小批发商 / 独立站卖家 / 进口采购经理 |
| 场景 | 他在什么情境下刷到你 | 通勤刷 TikTok、晚上在 FB 群里找供应商 |
| JTBD（要完成的任务） | 他真正想干成的事 | 找一个"靠谱、有产能、能小批量起订、能定制"的工厂 |
| 痛点 | 阻碍他完成任务的恐惧/麻烦 | 怕踩坑（质量/交期）、怕 MOQ 太高、怕沟通不畅、找厂太费时 |
| 顾虑/异议 | 他不下单的理由 | "你是不是中间商""有没有认证""能不能验厂" |
| 决策动机 | 让他行动的根本驱动 | 降低采购风险 + 提高利润 + 省时间 |
| 钩子/触发点 | 3 秒内能击中他的画面/话 | "走进一家真实的中国工厂" + 产能数字 + 装柜发货 |

**作用：投流时用画像反推三件事 ——（A）内容钩子（B）受众定向（C）卖点排序。**
没有画像 → 内容泛、痛点不准、3 秒划走率高 → CTR / 完播 / 转化全崩 → CPM 越投越贵。
有画像 → 内容"直戳痛点" → 高完播高互动 → 算法免费加曝光 + 降 CPM → 投流 ROI 拉高。

> 一句话：**工具决定你产多快，画像决定你投得准。投流效果的根在画像，不在剪辑软件。**

## 2. 你的两条业务线 —— 各一套画像 + 痛点 + 脚本模板

### 业务线 A：工厂展示视频（B2B，目标=询盘/加微信/找代理）

**核心画像（3 个典型）**
- 画像1「海外批发商/进口商」：要稳定货源、低 MOQ、有认证、能长期合作。痛点=怕质量翻车、怕产能跟不上。
- 画像2「亚马逊/独立站卖家」：要能贴牌(OEM)、能小批量、能定制包装。痛点=怕起订量太高、怕没人帮做产品差异化。
- 画像3「区域代理/分销」：要利润空间、要独家、要市场支持。痛点=怕拿不到好价、怕被厂家甩。

**痛点 → 钩子映射**
| 客户痛点 | 视频里要给的"证据" |
|---|---|
| 怕你是中间商 | 真实车间俯拍 + 老板/外贸经理真人出镜 |
| 怕没产能 | 多条产线、机器轰鸣、月产能数字字幕 |
| 怕质量差 | 质检镜头、原材料特写、CE/ISO/BSCI 认证 |
| 怕 MOQ 高 | 字幕直接打 "Low MOQ / Custom OEM available" |
| 怕交期/发货 | 仓库满货、装柜、"We ship to 60+ countries" |

**30–45 秒分镜脚本模板（工厂展示）**
```
0–3s   Hook：震撼车间俯拍 / 流水线推进镜头
        字幕："This is what a REAL [产品] factory looks like 🏭"
3–10s  规模产能：多产线 + 工人 + 数字（如 "Monthly capacity: 500,000 pcs"）
10–20s 质量工艺：原料特写 → 生产 → 质检 → 认证 logo（CE / ISO9001 / BSCI）
20–30s 合作政策：真人口播 "Low MOQ, OEM & ODM, free samples, custom packaging"
30–40s 信任收尾：仓库满货 → 装柜发货 → "Trusted by buyers in 60+ countries"
40–45s CTA：字幕+口播 "DM 'CATALOG' for price list 👉" + 屏幕贴二维码/主页引导
```

### 业务线 B：单品带货视频（B2C，目标=直接下单/进店）

**核心画像（按品类细分，举 3 例）**
- 家居收纳品 →「被杂乱逼疯的租房党/宝妈」：痛点=东西没处放、找不到。
- 健身/护具 →「久坐腰酸的上班族」：痛点=腰背疼、想偷懒也能练。
- 宠物用品 →「掉毛季崩溃的猫狗家长」：痛点=满屋毛、清理累。

**爆款结构（15–30 秒，TikTok/Reels 通用）**
```
0–3s   Hook（划走率生死线）：把"痛点场景"或"神奇效果"直接砸出来
        例："POV: 你家厨房永远是乱的" / 先放 before→after 的 after
3–8s   Problem：放大痛点（夸张演示那个烦人瞬间）
8–18s  Solution：产品登场 + 多角度 demo + before/after
18–25s Proof：数据/对比/评价弹幕（"10k+ sold""5★"）
25–30s CTA + Offer：限时折扣 + "Tap the cart / 链接在评论" + 价格锚点
```

**痛点挖掘实操（两条线通用）**
1. **扒评论**：竞品爆款视频评论区、Amazon 1–3 星差评、Reddit、Facebook 行业群。
2. **找原话**：搜 "I hate when…""is there a way to…""why is it so hard to…"，把用户原话直接写进字幕（用户语言 > 商家语言）。
3. **卖点翻译**：每个 feature 必须翻成 benefit。例：「304 不锈钢」→「能用 10 年不生锈，比你换 3 个便宜款还省钱」。

## 3. 创意总监视角：TikTok vs Facebook 的"原生形式"差异（决定装饰怎么加）

| 维度 | TikTok | Facebook / Reels |
|---|---|---|
| 画幅 | 竖屏 9:16 为主 | Reels 9:16；Feed 还吃 1:1 / 4:5 |
| 节奏 | 快、跳切多、3 秒强钩子 | 稍慢可，但**无声自动播放→字幕必备** |
| 声音 | 平台 **trending sound / 热门 BGM** 很重要 | BGM 次要，**Primary Text 文案权重高** |
| 字幕 | 逐字高亮（卡拉OK式）口语感 | 清晰大字幕、强调 CTA |
| 装饰 | 贴纸/箭头/emoji/进度条/手写圈重点 | 价格贴/CTA 按钮/品牌水印 |
| 标签 | #tiktokmademebuyit #factory #b2b #madeinchina | 兴趣定向 + Advantage+ 投放 |
| 调性 | UGC / 素人感 / 第一视角 | 可接受"更像广告"，信任背书更重要 |

**"平台生态装饰"清单（混剪时一键加）**：逐字高亮字幕、热门 BGM/原声、进度条、价格/折扣贴、箭头与圈重点、emoji 贴纸、转场、品牌水印 logo、结尾 CTA 贴纸。
> 这些"原生装饰"最快的实现方式 = **用剪映/CapCut 模板**（见工具链 pyJianYingDraft），因为模板本身就是平台爆款同款样式，天然"形式一样"。

## 4. 优秀同行在怎么做（可直接抄的范式）

- **工厂号范式**："factory tour" 第一视角带你逛厂 → 老板/sales 真人讲 MOQ 和定制 → 数字+对比制造震撼 → 装柜发货收尾 → 英文口播 + 大字幕。关键词去 TikTok/FB 搜 `#chinafactory #factorytour #manufacturer #wholesale #OEM`。
- **单品带货范式**：`#tiktokmademebuyit` 同款——3 秒强钩子、before/after、problem→solution demo、素人测评感、结尾限时 offer。

> 建议你自己也在 TikTok/FB 搜上面这些 hashtag，挑 10 条同品类爆款，逐条拆解它们的"前 3 秒钩子 + 字幕节奏 + BGM + CTA"，存成你自己的"对标库"。（TikTok/FB 都有登录与风控墙，机器人化采集容易被限，建议人工挑选最稳。）

## 5. 内容如何转化成"投流效果"（混剪的真正意义）

- **算法逻辑**：好内容 = 高 Hook rate（3s 完播）+ 高完播 + 高互动 → 平台白给曝光 + 压低 CPM。
- **混剪 = 工业化 A/B 测**：同一脚本批量生成多版本（换前 3 秒钩子 / 换 BGM / 换封面 / 换字幕），一次投十几条，跑出 winner 再放量。**这正是你要"AI 生成片段 + 批量混剪"的根本原因——素材会疲劳，必须工厂化持续产新。**
- **定向**：用买家画像做兴趣/行为定向；FB 用 Advantage+ / Lookalike；TikTok 用 Smart+ / 兴趣标签。
- **盯的指标**：Hook rate(3s) → 完播率 → CTR → 落地页/商品页 → CVR → CPA / ROAS。

# 关键结论
1. **真正"绑定平台生态 + 形式一样"靠三件事**：剪映/CapCut 原生模板（pyJianYingDraft）+ 平台热门 BGM + 原生字幕样式与 hashtag。工具只是执行。
2. **投流效果的根 = 买家画像 → 痛点 → 钩子**，不是剪辑软件。先把两条线的画像和"前 3 秒钩子库"建起来。
3. **混剪要工业化**：素材会疲劳，必须 AI 生成 + 批量混剪 + A/B 投放持续产新。
4. 已排除 MoneyPrinterTurbo；同类里更全的开源替代是 short-video-factory（量产）+ pyJianYingDraft（原生装饰）+ social-auto-upload/postiz（TikTok/FB 发布）。
