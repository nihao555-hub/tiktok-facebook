# 创意叙事大片模式（creative）·「造创意的机器」

对标拆解过的 **京东外卖《星球杯·黑牌》** 那类**高概念创意广告**：不是 UGC 带货，而是
电影质感的品牌创意片——借一个世界观演一个反转故事，把卖点演成剧情高潮，最后从软广丝滑
转硬广。这个模式把"为什么好看"工程化成一个公式，做到**可批量、每次创意点都不同**。

> 用法一句话：`template: creative`，选好卖点，引擎自动产一个**和历史都不撞款**的完整创意
> （世界观皮肤 + 逐秒脚本 + 分镜 image/motion 提示词），其余流水线（出图→图生视频→配音→
> 字幕→混剪→CapCut 草稿）原样复用。

## 一、创意公式（6 个变量轴）

```
一条片 = [世界观母题] × [违反常识的奇观] × [反转机制]
         × [卖点的视觉隐喻] × [软广转硬广的道具] × [解说/旁白腔调]
```

每个轴是一个**变量库**（见 `pipeline/creative_engine.py` 的 `AXES`，当前各 8-12 个值）：

| 轴 | 作用 | 例（部分） |
|---|---|---|
| `world` 世界观母题 | 给片子一张"皮肤"，换皮肤最直观拉开距离 | 星际竞技 / 武侠 / 东方神话 / 末日废土 / 赛博 / 谍战 / 怪兽都市… |
| `spectacle` 违反常识的奇观 | 0.5 秒钩子，开场就违反物理常识 | 时间静止 / 重力反转 / 物体自行运动 / 空间折叠 / 复制增殖… |
| `reversal` 反转机制 | 持续悬念引擎，每几秒一个意外 | 连环误导 / 身份反转 / 假危机真营销 / 反高潮 / 双重反转… |
| `metaphor` 卖点视觉隐喻 | 把卖点用画面"演"出来，不口播 | 卖点=超能力 / 关键道具 / 拟人登场 / 极限对比 / 倒计时救场… |
| `transition` 软广转硬广道具 | 故事丝滑接到品牌/促销 | 道具承接 / 台词双关 / 镜头穿越 / 同形转场 / 世界坍缩成 logo… |
| `narration` 解说腔调 | 声音决定气质，也是悬念引擎 | 体育解说 / 悬疑低语 / 说书评书 / 新闻播报 / 史诗预告 / rap… |

组合空间 ≈ **115 万种**。查看全部：

```bash
python -m pipeline.run --list-creative-axes
```

## 二、防同质化：用代码兜底，不靠 LLM 自觉

每抽一个新组合，引擎强制它**和历史里的每一条片至少有 `min_axes_different`（默认 3）个轴不同**，
否则重抽。历史按"创作线 `line`"持久化在 `creative_memory/<line>.json`（运行期状态，已 gitignore）。
所以同一条线连着跑，会越跑越不撞款——这是工程化的"每次创意点都要不同"。

- `--batch N` 一次产 N 个，**彼此之间**也满足 ≥N 轴不同。
- `lock` 可锁定某些轴（如永远武侠风），其余仍随机；锁太多时阈值会自动下调到可变轴数以内。
- `seed` 可复现某次组合。

## 三、逐秒叙事骨架

时间是相对节奏，按 `target_seconds` 等比缩放（见 `creative_engine.CREATIVE_BEATS`）：

```
0-2s    奇观钩子      —— 用[奇观]直接砸开场，0 铺垫，1 秒内"这不可能"
2-10s   立世界观+悬念  —— 用[世界观]+[解说腔调]立住设定，抛悬念
中段     连环反转升级  —— 用[反转机制]每 3-6 秒一个意外，赌注升级
后段     卖点高潮揭晓  —— 用[卖点视觉隐喻]把卖点演成扭转全局的最大反转
        软广转硬广    —— 用[软广转硬广道具]丝滑接到品牌/促销
58s+    品牌定帧+CTA  —— 品牌强资产 + 记得住的 slogan + 促销
```

LLM 拿到"固定的轴组合 + 这套骨架 + 卖点"后，在轴内自由编故事写脚本（`prompts/creative_persona.md`
是喂给它的创意总监角色）。无 LLM key 时用确定性兜底脚本，仍按组合+骨架产出可跑通的片子。

## 四、怎么用

### A. 跑完整出片
```bash
cp config.creative.example.yaml config.yaml   # 改成你的卖点
python -m pipeline.run --config config.yaml
# 产物：output/<project>/final.mp4 + script.json + capcut_draft/
```

### B. 只批量产创意点子（不出片，最快头脑风暴）
```bash
python -m pipeline.creative_engine --batch 5 --selling-point "最快分钟级送达" --brief
# 每个创意打印：6 轴组合摘要 + 喂 LLM 的指令块 + 逐秒骨架；并写入历史保证后续不撞
```

### C. 固定风格 / 复现
```bash
python -m pipeline.creative_engine --batch 3 --lock world=wuxia --seed 42 --no-record
```

## 五、和已有"差异化层"的关系

仓库已有的 `brand.py`（品牌母题 + 钩子轮换 + 反重复）服务的是 UGC 带货片（product/factory）。
创意模式新增的 `creative_engine.py` 是**叙事大片专用**的另一套防同质化引擎：前者保证"同一品牌每条
不同"，后者保证"高概念创意每条不撞款"。两者互不干扰，各自有独立的记忆目录
（`brand_memory/` vs `creative_memory/`）。
