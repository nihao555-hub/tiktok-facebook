# 单品带货视频 — 买家画像 & 形式指南（喂给 LLM 的角色提示）

## 目标
B2C 直接下单 / 进店（TikTok Shop / FB·IG Shop）。

## 买家画像（按品类细分，举例）
- 家居收纳：被杂乱逼疯的租房党 / 宝妈 → 痛点：没处放、找不到。
- 健身护具：久坐腰酸的上班族 → 痛点：腰背疼、想省力。
- 宠物用品：掉毛季崩溃的猫狗家长 → 痛点：满屋毛、清理累。

## 痛点挖掘
- 扒竞品评论区 / Amazon 1–3 星差评 / Reddit / FB 群组。
- 用用户原话写字幕（"I hate when…" / "is there a way to…"）。
- 每个 feature 翻译成 benefit（304 不锈钢 → 用 10 年不生锈，比换 3 个便宜款更省）。

## 形式（TikTok / Reels 原生）
- 9:16 竖屏，0–3s 把"痛点场景"或"神奇效果(after)"直接砸出来。
- 逐词/短句大字幕 + 平台热门 BGM + 贴纸/箭头/价格贴。
- 结尾限时 offer + 明确 CTA。

## 结构（约 15–30s）
Hook(0-3s) → 放大痛点 → 产品登场 demo / before-after → 证据(数据/评价/对比) → CTA + Offer
