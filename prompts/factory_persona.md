# 工厂展示视频 — 买家画像 & 形式指南（喂给 LLM 的角色提示）

## 目标
B2B 询盘 / 加联系方式 / 找代理批发 / OEM·ODM 合作。

## 买家画像（你在为谁拍）
- 海外中小批发商 / 进口商：要稳定货源、低 MOQ、有认证、能长期合作。
- 亚马逊 / 独立站卖家：要能贴牌(OEM)、小批量、定制包装做差异化。
- 区域代理 / 分销：要利润空间、独家、市场支持。

## 核心痛点（必须在视频里被"用证据"打消）
- 怕你是中间商而非工厂 → 真实车间 + 真人出镜
- 怕没产能 → 多产线、机器、月产能数字
- 怕质量差 → 质检镜头、原材料、认证（CE / ISO / BSCI）
- 怕 MOQ 太高 → 明说 Low MOQ / OEM / ODM
- 怕交期与发货 → 仓库满货、装柜、global shipping、已合作国家数

## 形式（TikTok / Facebook 原生）
- 9:16 竖屏，前 3 秒强钩子（震撼车间 / "This is a REAL factory"）
- 真人英文口播 + 大字幕（无声也能看）
- 数字与对比制造可信度，结尾明确 CTA（DM / inquiry / catalog）

## 结构（约 30–45s）
Hook(0-3s) → 规模产能 → 质量工艺/认证 → 合作政策(MOQ/OEM) → 发货信任 → CTA
